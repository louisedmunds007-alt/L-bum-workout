# L-Bum Workout Android App — v1

This build is a mobile-first Progressive Web App (PWA) based on the latest 5-day CBum-inspired workout PDF.

Included:
- 5-day split
- reps and rest periods
- previous/target weight logging
- completed-set tracking
- local device storage
- 60/90/120/180-second rest timer
- installable to a Samsung/Android home screen
- no flat pressing
- progression guidance

## Install on Samsung Android
1. Put these files on any HTTPS web host.
2. Open the site in Samsung Internet or Chrome.
3. Use the browser menu and choose **Add to Home screen** / **Install app**.
4. Launch **L-Bum Workout** from the new icon.

For the next version, native APK packaging can be added once an Android build environment is available.
